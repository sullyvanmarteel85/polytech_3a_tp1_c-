Pour compiler:
make backend

Pour compiler avec le gui:
make gui

Pour lancer le programme:
make run

Pour lancer l'écoute sur le port local:
make listen


Pour faire un test complet sans connexion au LimoBot:
Compiler le programme.
Taper dans un terminal secondaire à la racine du projet "make listen"
Taper dans le terminal courant à la racine du projet "make run"
Lors du choix de l'ip, taper "127.0.0.1" au lieu de l'adresse ip du LimoBot.
